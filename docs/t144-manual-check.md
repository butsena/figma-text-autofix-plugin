# T-144: короткая проверка Figma

Готовая версия — **Text Autofix — T-144 QA (smoke)**:
/Users/a.butsenko/Desktop/figma-text-autofix-plugin-t144-smoke/manifest.json

Импортировать через Development → Import plugin from manifest. Собирать или объединять в терминале ничего не нужно. Это отдельная сборка с plugin_version=smoke; рабочие показатели исключают её события. Прежняя T-144 QA (analytics off) не отправляет события.

1. **Обычное исправление.** На копии тестового фрейма создать слой «Кватира», запустить новую версию и при необходимости включить проверку орфографии. Исправить по подсказке. Получится «Квартира» один раз; в отчёте будет успешное исправление.
2. **Правка удалённого слоя.** В другом тестовом фрейме создать новый слой «Кватира», открыть эту версию и дождаться карточки исправления. Пока плагин открыт, удалить именно этот тестовый текстовый слой в макете. Вернуться к прежней карточке и один раз нажать «Исправить». Слой не восстановится, успешное исправление не должно появиться. Старая карточка может остаться — это прежнее поведение, её исчезновение не критерий T-144.

Сообщить результат обоих примеров и имя smoke-версии. Codex сверит события сессии: обычный успех и одна plugin_error/manual_apply/node_missing/failed для удалённого слоя без второго ui и без ложного applied. Самостоятельно искать строки в отчёте не требуется: smoke там исключён.

QA #51/#60 ожидают проверки. Агент не ставит ручной passed до подтверждения пользователя. Удаление нужно только для воспроизводимого тестового сбоя на копии фрейма.
