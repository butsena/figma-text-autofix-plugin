## Смысл

Одна полученная запись описывает проблему конкретной операции/ресурса. Это не число неуспешных проверок и не процент успеха. Отдельно показываются:

- **Сбой действия**: проверка, применение, сохранение решения или восстановление оформления не удались.
- **Восстановлено**: обновление словаря не удалось, но подтверждённо использована встроенная/сохранённая копия.
- **Исход неизвестен**: старые записи без нового поля; их смысл и историю не пересчитываем.

Разделение согласовано Антоном 28.10.2026. Новый формат не доказывает полноту доставки. При отсутствии записей до начала нового учёта показывается «—». Первая дата — дата первого полученного рабочего события с новым исходом, а не дата разработки/сборки и не начало гарантированного покрытия.

## Покрытие и владелец записи

| Ситуация | Учёт | Владелец |
| --- | --- | --- |
| Исключение ручного исправления/пропуска/сохранения решения | failed, manual_apply; исходный scan сохраняется, если известен | handleUiMessage; main только показывает прежнюю ошибку |
| Исключение начального запуска вне UI-маршрута | failed, open или известный исходный этап | main |
| Исключение сканирования | failed, scan/scan_failed | сканирование только аннотирует; запись на границе операции |
| Не загрузился нужный шрифт для правки | failed, auto_apply/manual_apply, font_load_failed | apply; одна запись на шрифт/слой в операции, включая повторные auto-проходы |
| Запись текста не удалась / слой исчез | failed, apply_failed/node_missing | apply или явная проверка ручного действия |
| Оформление восстановить не удалось | failed, style_restore_failed | apply; подтверждённая замена текста остаётся успешной |
| Не обновился редакционный список / дополнительный список орфографии, встроенная копия восстановлена | recovered, resource, bundled | runRemoteRefresh, один раз на реальную попытку |
| Hunspell не загрузился, пригодная сохранённая копия использована | recovered, spell_dictionary, cache | spellDictionaryFromCache |
| Hunspell недоступен без пригодной копии | failed, spell_dictionary | failSpellDictionary |
| Инициализация орфографии выбросила исключение | failed, spell_init_failed | catch орфографического этапа, остальные правила продолжают прежнюю работу |

Один и тот же объект Error в двух действиях — две проблемы. Нет глобальной дедупликации по session+code или Error. Для повторного шрифта используется только локальный набор операции; разные шрифты и слои не склеиваются.

Не считаются проблемой: пустое выделение/намеренное отключение орфографии, устаревшая карточка без изменения текста, обычный доступ к свежему кэшу, предварительная загрузка шрифта с последующим успешным применением. Кэш может быть запасным источником без сетевой попытки — это нормальная работа, не восстановление.

Явно вне покрытия: аварийное уничтожение среды, штатный крестик, пропавшая сеть аналитики, каждое диагностическое предупреждение кэша, ненаблюдаемые сбои Figma. Нет гарантии доставки или восстановления исторических ошибок.

## Совместимый контракт

Событие по-прежнему plugin_error, schema_version=1. Прежние stage/code принимаются. Новые безопасные поля:

- outcome: failed/recovered; отсутствующее поле остаётся отсутствующим;
- resource: replacements/boundary_exceptions/ambiguous_forms/spell_dictionary/spell_supplement/spell_whitelist;
- recovery: bundled/cache, только при подтверждённом восстановлении соответствующего ресурса.

Новые коды: scan_failed, spell_init_failed, style_restore_failed. Клиент и коллектор проверяют согласованность списков, этапов и сочетаний. Лишние поля отбрасываются; тексты/имена/URL/stack/слои не попадают в запись. Отказ аналитики не меняет продуктовый результат. Очередь, retry, постоянные ID и дополнительная отправка при закрытии не добавлены.
