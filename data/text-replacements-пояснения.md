# Справка для редакторов (не участвует в сборке плагина)

## Как устроены правила

- **Гибрид:** простые замены — в таблице; нетривиальная логика — в коде плагина.
- Колонки:
  - **тип** — `exact` | `spell` | `join` | `lemma` | `phrase` | `special`
  - **найти** — исходные варианты через запятую (для `spell`/`join` — основа слова)
  - **заменить** — канонический текст (нижний регистр; регистр в тексте подставится сам)
  - **формы** — необязательно; пары словоформ для `lemma`/`phrase`: `было=стало; а|б=в`
  - **пояснение** — необязательно
- Регистр **не дублируем**: достаточно `далее → дальше`. Сработает и «Далее», и «ДАЛЕЕ».
- **Сопоставление:** целое слово/фраза по границам кириллицы.

## Типы

| тип | Когда | Пример |
|---|---|---|
| `spell` | Меняются буквы корня, окончания те же | `риэлтор → риелтор` (все падежи сами) |
| `join` | Дефис/пробел → слитно, окончания те же | `промо-код, промо код → промокод` |
| `exact` | Одна точная замена | `далее → дальше`, `тыс. → тыс` |
| `special` | Особый символ/сжатие | `рубль, рубля, рублей, руб. → ₽` |
| `lemma` | Синоним с другой парадигмой | `приобрести → купить` + колонка **формы** |
| `phrase` | Многословная замена с формами | `денежные средства → деньги` + **формы** |

## Рабочий поток

1. **Редакторам:** правки словаря — PR в public-репозиторий  
   https://github.com/butsena/text-autofix-replacements  
   Файл: `text-replacements.csv`.

2. **После merge в lexicon:** плагин подхватит словарь при следующем запуске (без пересборки).  
   Разработчикам — обновить bundled fallback в основном репо (см. `docs/migration-sheet-to-github.md`).

3. **Парадигмы (опционально):** длинные списки форм можно держать в `data/replacement-paradigms/<найти>-<заменить>.txt` и подставлять:
   ```bash
   node scripts/build-text-replacements.mjs --expand --write
   ```

## Дополнительные колонки (необязательно)

Можно добавить: `включено`, `приоритет`, `категория` — их читает парсер (см. `src/lexicon/replacement-rows.ts`).

Старый формат из двух колонок (`исходные варианты,верный текст`) по-прежнему читается как набор `exact`-правил.
