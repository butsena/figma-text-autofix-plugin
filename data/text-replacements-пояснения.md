# Вкладка «Пояснения» (не для сборки плагина)

Содержимое этого файла — справка для редакторов. В **Google Таблицах** держите на **первом листе** только таблицу правил (как в `text-replacements.csv`), а сюда скопируйте текст второго листа или ведите второй лист параллельно и не экспортируйте его в CSV для плагина.

## Как устроены правила (первый лист)

- **Гибрид:** простые замены — в таблице; нетривиальная логика — в коде плагина.
- **Колонка 1** — исходные варианты **через запятую** (одинаковые по смыслу написания).
- **Колонка 2** — единственно верный текст замены.
- Если в **одном варианте** нужна запятая, оформите всю первую ячейку в кавычки: `"Слово, с запятой",Другое`.
- **Сопоставление:** целое слово по границам кириллицы (например «Далее» в кнопке, не часть другого слова).

## Рабочий поток

1. **Импорт в Google Таблицы:** Файл → Импорт → CSV первого листа → разделитель «запятая», кодировка UTF-8.
2. **Для плагина:** после правок на первом листе — Файл → Скачать → **только лист с правилами** → CSV; замените в репозитории файл `data/text-replacements.csv` и пересоберите плагин.

## Дополнительные колонки (необязательно)

На первом листе можно добавить колонки с заголовками: `включено`, `пояснение`, `приоритет`, `категория` — их читает парсер (см. `src/sheet/replacement-rows.ts`).
