# Справка для редакторов (не участвует в сборке плагина)

## Как устроены правила

- **Гибрид:** простые замены — в таблице; нетривиальная логика — в коде плагина.
- **Колонка 1** — исходные варианты **через запятую** (одинаковые по смыслу написания).
- **Колонка 2** — единственно верный текст замены.
- Если в **одном варианте** нужна запятая, оформите всю первую ячейку в кавычки: `"Слово, с запятой",Другое`.
- **Сопоставление:** целое слово по границам кириллицы (например «Далее» в кнопке, не часть другого слова).

## Рабочий поток

1. **Редакторам:** правки словаря — PR в public-репозиторий  
   https://github.com/butsena/text-autofix-replacements  
   Файл: `text-replacements.csv`.

2. **После merge в lexicon:** плагин подхватит словарь при следующем запуске (без пересборки).  
   Разработчикам — обновить bundled fallback в основном репо (см. `docs/migration-sheet-to-github.md`).

## Дополнительные колонки (необязательно)

Можно добавить колонки: `включено`, `пояснение`, `приоритет`, `категория` — их читает парсер (см. `src/lexicon/replacement-rows.ts`).
