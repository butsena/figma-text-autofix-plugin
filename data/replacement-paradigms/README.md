# Парадигмы для lemma/phrase

Файлы вида `<найти>-<заменить>.txt` — опциональный офлайн-источник колонки **формы**.

Формат строки:

```text
приобрёл|приобрел=купил
приобрела=купила
```

Подстановка в CSV:

```bash
npm run build:replacements -- --expand --write
```

Если колонка **формы** в CSV уже заполнена, файл парадигмы не нужен: плагин читает CSV как есть.
